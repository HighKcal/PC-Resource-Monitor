# 합성 HTML A/B 화면 시안

`open.cmd`를 실행하거나 `dist/index.html`을 브라우저로 열면 동봉한 HTML/CSS/JavaScript와 고정 합성 fixture로 화면 시안을 볼 수 있다. 외부 패키지 설치나 서버는 필요 없다. `dist`는 이 시안의 직접 실행 자료이므로 제출에 포함한다.

과거 A/B 정보 배치 비교용 자료이며 현재 C 제품과 기능·단위가 모두 일치하지 않는다. 실제 수집·DB·Baseline 결과, 최신 검색/정렬/그룹 기능이나 관리자 GUI 검증을 대신하지 않는다. 현재 제품은 A안의 목록+오른쪽 상세 구조를 사용하며 [C 화면 안내](../../docs/native-ui.md)를 기준으로 읽는다. 과거 캡처·개인 환경의 검증 manifest와 인계 자료는 로컬에 보존한다.
